# Галерея концепций главной

Маршрут: `/concepts/`. Задача — показать клиенту варианты первого экрана и дать
возможность рассмотреть каждый в полном размере.

## Состав

Исходные варианты 01–03 сохранены: «Собранный механизм», «Выставочная типографика»,
«Привычный сайт агентства».

30 сентября 2026 года по запросу пользователя добавлены подготовленные
изображения 04–08: «Сцена A1», «Крупный план», «Живой цвет», «Графический монтаж»,
«Привычная агентская подача». Все изображения — PNG 1536 × 1024 px.

Описания новых карточек характеризуют соответствующий макет: композицию,
типографику, графику и палитру. Содержимое изображений при переносе не меняется.

## Формат и поведение

Каждая карточка содержит превью, номер, палитру, название, короткое описание,
разделы «Характер» и «На что обратить внимание», ссылку «Рассмотреть макет».
Сетка и оформление наследуются от исходной галереи.

Нажатие открывает общий просмотр с названием, счётчиком и переходами между
восемью вариантами. Поддерживаются стрелки клавиатуры, Escape и ссылка
«Полный размер». Без JavaScript ссылки открывают сами PNG.

Галерея сохраняет `noindex, nofollow`. Она служит для обсуждения, не фиксирует
выбранный дизайн и не меняет страницы содержательного прототипа.

## Подборки и V2 — 2 октября 2026 года

На всех трёх страницах появилась общая навигация: V1 (`/concepts/`),
V2 (`/concepts/v2.html`) и ранние варианты (`/concepts/previous.html`).
V1 содержит существующие четыре обновлённых макета 2А, 3А, 2Б и 3Б с демонстрацией
движения; ранняя подборка сохраняет восемь исходных концепций.

По прямому запросу пользователя V2 содержит ровно три актуальных изображения:

1. «Проектный альбом» — `assets/v2/project-album-v2.png`.
2. «Связанные направления» — `assets/v2/connected-directions-v2.png`.
3. «Просторная студия» — `assets/v2/spacious-studio-v2.png`.

Это подготовленные макеты из отдельного проекта `a1-design`, по 1536 × 1024 px.
Исходные версии с плотным шрифтом и каталожные референсы Impeccable в V2 не входят:
пользователь уточнил состав публикации. Пиксельные данные трёх PNG сохранены;
из публичных копий удалены только текстовые метаданные с внутренними промптами.
Происхождение и контрольные суммы указаны в `docs/concepts-v2-assets.json`.

Просмотр V2 открывается по нажатию на превью или ссылку. Есть переключение
между тремя изображениями, стрелки клавиатуры, Escape, возврат фокуса к исходной
карточке, масштаб 100% и ссылка на исходный PNG. На телефоне карточки идут в одну
колонку; крупный макет можно прокручивать. Без JavaScript ссылки открывают PNG.
Публикация не означает выбор или утверждение направления.

## Подборка V3 — 4 октября 2026 года

Подборка `/concepts/new-version/` включена в общую навигацию как вкладка V3.
Вкладка доступна из V1, V2 и ранних вариантов; на V3 есть обратные переходы.
Содержимое всех подборок и существующие адреса сохранены. V3 содержит шесть
макетов с номерами 4–9, описания для заказчика и просмотр в полном размере.
