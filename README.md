# a1

Стартовый репозиторий для сайта digital-agency.

Направление: современный сайт digital-агентства в стилистике утвержденной главной страницы.

## Актуальный прототип

- Утвержденная главная: `prototype/index.html`
- Публикация: https://imperil03.github.io/a1/prototype/

## Правила проекта

- `AGENTS.md` - инструкции для Codex/агентов перед работой с проектом.
- Старые корневые прототипы, примеры и референсы удалены, чтобы не смешивать стили.
