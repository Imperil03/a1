# Расширенные макеты 04, 05, 07, 10 и 11

8 октября 2026 года по запросам пользователя подготовлены продолжения пяти выбранных направлений. Каждая страница показывает первый экран и отдельный длинный статичный макет услуг, кейсов и системного подхода.

- `04.html` — «Живая типографика»: открытые строки услуг, коралловые акценты, тёмный блок кейсов.
- `05.html` — «Масштаб и живая лента»: светлая композиция, изумрудно-оранжевая круговая графика и мятные карточки.
- `07.html` — «Поток — больше воздуха»: кремовые разделы, металлические ленты, тёмно-зелёные кейсы. Пояснение и два действия расположены под первым экраном.
- `10.html` — «Живой цвет»: оранжево-индиговая пигментная графика, светлые услуги и тёмные кейсы; развивается ранний вариант 06.
- `11.html` — «Привычная агентская подача»: светлый первый экран с тёмной панелью услуг, просторные карточки и сдержанная типографика; развивается ранний вариант 08.

Для 10 и 11 первые экраны развёрнуты на полный viewport; прежняя короткая полоса услуг перенесена в полноценный следующий раздел. В V3 номера 06 и 08 уже заняты другими концепциями, поэтому добавлены новые номера без замены прежних. Между пятью расширенными макетами можно переключаться в верхней и нижней навигации.

Макеты созданы встроенным генератором изображений для сравнения дизайна. Это фрагменты главной для компьютера, а не готовые страницы сайта. Управление галереей адаптировано под узкий экран; кнопку «Крупнее» можно использовать для просмотра деталей. Без JavaScript страницы и переключение вариантов остаются доступны.

Все четыре исходных текстовых блока также доступны под макетом в раскрываемом разделе. При экспорте их текст сверяется с `prototype/index.html` после нормализации только пробелов. Источник совпадает со снимком от 3 октября: Git blob `07dd490c0c494e2775f65564bfc54d6cdf9780f6`. Числа и результаты являются данными прототипа, отдельной проверкой кейсов публикация не является.

Исходные PNG первых экранов используются по прежним ссылкам. У публичных копий новых изображений удалены служебные метаданные; пиксельные данные сохранены. Промпты и материалы подготовки хранятся только в локальном проекте. Окончательное направление ещё не выбрано.

По дополнительному запросу 8 октября продолжения обновлены: увеличены паузы между разделами и внутренние поля, уменьшены заголовки и выровнена типографическая иерархия. У 05 также убраны повторные номера шагов. Первые экраны и исходные тексты сохранены. Для новых изображений используется параметр версии, чтобы браузер загружал актуальные макеты.

По следующему запросу фиолетовое семейство варианта 05 заменено на изумрудное и мятное в первом экране и продолжении. Композиция и оранжевые акценты сохранены; исходная фиолетовая версия остаётся в локальном архиве.
