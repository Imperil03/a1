# Подборка дизайна A1

Клиентская галерея V3: `/a1/concepts/new-version/`. С 4 октября 2026 года доступна через общие вкладки V1, V2, V3 и «Ранние варианты» в `/a1/concepts/`.

Основной фон V3 — `#f6f7fa`, как у V1 и V2.

8 октября добавлены [расширенные макеты](extended/README.md) выбранных направлений 04, 05 и 07. Ссылки находятся над подборкой и в соответствующих карточках. Все шесть первых экранов сохранены.

Цель — сравнить восемь актуальных вариантов главной страницы с номерами 4–11, рассмотреть изображения в полном размере и сообщить выбранный вариант.

## Содержание и поведение

- Карточки содержат номер, название, описание композиции и замысел анимации. Изображения статичные.
- Просмотр макета: кнопки перехода, стрелки клавиатуры, Escape, масштаб 100% и открытие исходного PNG.
- Выбор сохраняется только в браузере посетителя. Готовое сообщение с номером и ссылкой можно скопировать и отправить команде проекта самостоятельно. Серверной отправки ответа нет.
- Ссылки `#variant-04`–`#variant-09` открывают соответствующий макет.
- Страница работает как самостоятельный статичный сайт. Сборка, внешние библиотеки и локальный сервер Impeccable не требуются.
- Без JavaScript доступны изображения, тексты и прямые ссылки на PNG.
- На узком экране карточки идут в одну колонку. Учтены клавиатура, видимый фокус и уменьшение движения.

## Материалы и публикация

Файлы PNG сохраняют пиксели исходных макетов 1536 × 1024. Из публичных копий удалены служебные метаданные генерации. Шрифт Onest распространяется с приложенной лицензией OFL.

Галерея содержит варианты 4–11. По запросу пользователя добавлены 10 «Живой цвет» и 11 «Привычная агентская подача», развивающие одноимённые направления из ранней подборки. Описания подготовлены для заказчика и не содержат внутренних комментариев. Расширенные макеты доступны для 04, 05, 07, 10 и 11.

Первоначальная публикация добавила только эту папку. Позднее во все галереи добавлена общая вкладка V3. Содержимое других подборок, прототип, маршруты и настройки GitHub Pages сохранены. Страница имеет `noindex, nofollow` и предназначена для согласования дизайна, а не для продвижения в поиске.
