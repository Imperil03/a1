# Полная главная — направление 11

Дизайн A1 в выбранном направлении «Привычная агентская подача». Это материалы для согласования, не завершённый production-сайт.

На10октября пользователь предпочёл полную версию в Onest. Основные переходы варианта11 в галерее ведут на неё. Текущий код служит дизайн-пробой; выбранный стек финальной реализации — Astro, TypeScript и CSS.

- `11.html` — составной макет с прежними изображениями; услуги и системный блок представлены живыми фрагментами.
- `11-onest.html` — вся главная с настоящим Onest: HTML-текст, адаптивная композиция, исходные фотографии и логотипы. Позволяет оценить выбранный шрифт по всей странице. Прежний макет доступен по ссылке сверху.

Порядок: первый экран → кейсы → услуги → системный подход → преимущества → этапы → команда и директор → сертификаты и клиенты → отзывы → FAQ → контактный блок → подвал.

## Последние решения пользователя

Onest выбран окончательно; сравнение с Manrope убрано. Сохранены светлая основа, сливовый текст и панели, оранжевые акценты направления11.

Для выбора замены светлых сиреневых подложек доступны три пробы: `11-onest.html?surface=neutral#director` — серый, `?surface=warm#director` — тёплый серый, `?surface=mint#director` — мятный. Переключатель сверху позволяет сравнить их на той же позиции страницы, включая исходный вариант. Пробы меняют светлые подложки и связанные элементы; оранжевые акценты и тёмные панели сохраняются. Без параметра `surface` показывается исходная палитра. Окончательный выбор пока не сделан.

Кейсы — шесть светлых цветных карточек с простыми предметными иллюстрациями, всеми заголовками, результатами и метками внутри. Изображения концептуальные, не скриншоты клиентских проектов. Для HTML-пробы графика вынесена в прозрачный атлас `assets/onest-case-atlas.png`; текст остаётся доступным и набран Onest.

Услуги — раскрывающийся список из четырёх направлений без крупных картинок и явных кнопок «Подробнее». Все названия и цены видны в списке, одно описание открывается по нажатию. Исходные подписи переходов сохранены как доступные названия стрелок. Четыре основных ссылки ведут на проверенные опубликованные страницы прототипа. Дополнительные направления — статичный список с небольшими тематическими иконками: их страницы в исходнике пока возвращают404.

Системный блок — связанная цепочка аудитории, сайта и аналитики. Все пояснения видимы; линии сходятся к выделенному тёмному результату. На телефоне цепочка вертикальная.

Преимущества: опыт с2013года выделен отдельной светлой панелью, четыре остальных аргумента — рядом с компактными иконками. Все описания сохранены и видимы. Фоны секций, включая hero, систему, этапы, отзывы, контакты и футер, занимают всю ширину экрана; центральные контентные обёртки ограничены1536px.

## Контент и материалы

Источник — `prototype/index.html`, Git blob `07dd490c0c494e2775f65564bfc54d6cdf9780f6`. Тексты сохраняются дословно по смысловым блокам. Их перенос не подтверждает рабочие коммерческие данные исходника.

Пять фотографий сотрудников и фото директора взяты из предоставленных исходных материалов и сопоставлены с именами на странице компании. У Егора фотография не назначена; его имя и роль сохранены с нейтральным обозначением. Восемь сертификатов/статусов и восемь клиентских логотипов сохранены.

В полной HTML-пробе доступны все6 отзывов и8 полных ответов FAQ. Отзывы переключаются вручную и доступны в горизонтальной ленте; FAQ поддерживает несколько открытых ответов. Меню и фокус поддерживают клавиатуру, предусмотрено уменьшение движения. Неизвестные/неподготовленные подуслуги не выдаются за рабочие внутренние страницы.

В `11.html` дополнительно остаётся текстовое приложение из13 исходных блоков. Режим «Телефон» в нём показывает три ключевые композиции; `11-onest.html` адаптирует всю главную целиком.
