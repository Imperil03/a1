# Полная главная — направление 11

Статичный дизайн главной A1, подготовленный 9 октября 2026 года по выбранному направлению «Привычная агентская подача» и согласованному брифу. Просмотр: `11.html`.

Порядок: первый экран → кейсы → услуги → системный подход → преимущества → этапы → команда и директор → сертификаты и клиенты → отзывы → FAQ → контактный блок → подвал.

Раздел кейсов обновлён по отзыву пользователя и присланному скриншоту Up Advert: шесть светлых цветных карточек с простыми предметными иллюстрациями. Заголовки, результаты, подписи и метки находятся внутри карточек. Сложные сцены и тёмные заливки из предыдущей версии отклонены пользователем. Изображения служат концептуальными обложками, не скриншотами клиентских проектов. Все названия, метки и показатели сохранены. Первый кейс также показан в мобильной композиции.

Текущие изображения кейсов — `01-cases-light.png` и `mobile-cases-light.png`. Предыдущие `01-cases-visual.png` и `mobile-cases-visual.png` больше не используются на странице.

Услуги переработаны в открытый каталог: четыре широкие строки, отдельная колонка названия и стоимости, тёмные крупные абзацы справа и предметные иллюстрации вместо контурных иконок. Все исходные описания, метки, цены и действия сохранены. Изображения — `02-services-editorial-a.png`, `02-services-editorial-b.png`, `mobile-services-editorial.png`.

Исходные изображения первого экрана, системного подхода и мобильного отзыва сохранены без изменения пикселей: просмотрщик показывает нужные участки через окна CSS по границам секций (1535 px для начала системного подхода, 1600 px для конца мобильного hero, 1232 px для начала мобильных отзывов).

Макет собран из последовательных изображений, чтобы сохранять читаемый размер текста. Для отзывов доступны два состояния по три карточки. FAQ показан с первым открытым ответом; все восемь полных ответов доступны в текстовом приложении. Режим «Телефон» показывает три ключевые мобильные композиции, а не полную мобильную реализацию.

Фотографии команды взяты из исходных материалов и сопоставлены с именами на странице компании. У Егора в источнике фотография не назначена; его имя и роль сохранены с нейтральной пиктограммой. Реальные фотографии и логотипы остаются материалами для последующей реализации.

Под изображениями доступны 13 текстовых блоков источника, включая навигацию, подвал, все отзывы и ответы FAQ. Экспорт сверяет текст с исходным HTML после нормализации пробелов. Источник `prototype/index.html`, Git blob `07dd490c0c494e2775f65564bfc54d6cdf9780f6`. Это проверка редакции, не фактчек рабочих коммерческих данных. Изображения проверяются визуально; автоматическая сверка каждого символа внутри PNG не выполнялась.

Управление просмотром поддерживает клавиатуру, переключение формата и увеличение. Без JavaScript остаются доступны оба формата, текстовое приложение и прямая ссылка на вторую группу отзывов. Все изображения и шрифт размещены локально, внешних библиотек и аналитики нет. Страница имеет `noindex, nofollow`.

Публичные PNG очищены от служебных метаданных. Процесс создания, точные промпты и исходные изображения сохранены в локальном проекте. Это дизайн для обсуждения перед разработкой, не готовый сайт агентства.
