# Клиентский журнал работ A1

Этот файл нужен для понятного отчета клиенту в конце месяца. Сюда попадают только значимые работы: новые страницы, SEO-структура, важные UX-доработки, контентные блоки, технические улучшения, аналитика и исправления, которые влияют на результат.

Мелкие внутренние правки не записываем отдельно. Если несколько небольших задач дают один понятный результат, объединяем их в один пункт.
